# 当前可见区域截图与标注

## 范围

0.6.0-screenshot/code17。普通控制区“截图标注”与USB诊断同一行；全屏画面右下方有小“截图”入口。点击后暂停并冻结当前画面，按当时的1～4倍缩放、平移合成截图；保留视口可见黑边，不包括应用HUD、进度条、按钮或系统栏。清晰度按屏幕视频视口，不承诺源帧分辨率。

## 使用

1. 通过视频、逐帧或TourBox找到画面，可先放大和拖动，再点击截图。
2. 静态面板中选直线、箭头或圆圈（可画椭圆），选红、黄或蓝，单指按住拖动，松手提交。
3. 支持撤销、清空；两指或拖出图片区域取消本笔，不把预览留白当图片坐标。每张最多200项标注。
4. 点击“另存PNG”，选择位置；取消选择器保留编辑，成功写入、flush及close后才报告保存成功。
5. 关闭编辑后视频保持暂停。未保存图片或标注需确认丢弃；保存后再改动会重新标为未保存。

## 实现与保护

- ShotModel：归一化图像坐标、fit-center预览映射、视口变换、标注历史、唯一任务代次和保存原子提交；纯JVM可测。
- prepareScreenshot：现有播放器忙状态串行暂停，并查询pause核实；不改USB或播放核心。initializePaused仅供截图流程恢复，普通选片仍自动播放。
- ViewportCapture：只读取MpvView内部匹配尺寸的SurfaceView（PixelCopy）或TextureView（getBitmap），再按冻结变换合成视口。禁止整窗口/View.draw假代替。暂停后等待显示回调；原生复制超时不自动重试，在回调归还前不回收其Bitmap、不再启动同一捕获器的新复制。
- AnnotationView和ShapeRenderer：预览与成片共用图片坐标渲染；横竖屏改变预览尺寸，不改变标注坐标。截图过程中布局/会话变化使结果失效。
- ScreenshotWriter：应用上下文与专用后台线程；保存快照不变，编码期间工具暂时不可操作。Bitmap所有者和工作租约保证关闭面板后仍在写入的图像不会提前回收。
- 截图/编辑/另存与视频导出互斥，暂停播放器屏幕及TourBox分发，保留USB原始监听；系统保存选择器若使Activity进入后台，沿用已有USB关闭/返回重连规则。编辑期间返回前台不触发自动播放；若系统选择器导致播放器释放，退出编辑后按暂停状态重建。
- 另存从不写源视频；拒绝可识别的相同URI/文档别名，失败尽力移除本次目标半成品，不自动重试。进程被杀后未保存编辑不恢复。

## 限制与验收

- 捕获最多8百万像素，ARGB_8888图像有多份缓冲峰值；无有效帧、不支持的渲染结构、内存不足或超时明确失败。
- 未新增依赖、JNI、USB私有命令；未修改8/26/94字节初始化、输入映射、USB回收及视频导出范围。
- HDR颜色、硬件Surface合成、实际裁切与旋转需真机验收，API返回成功不等于画面正确；本轮未访问ADB/设备或安装APK。
- 实际无设备检查：截图377、UI47、自动初始化124、映射318、播放器186、输入497、异步回收105、连接代次48、导出191断言通过；94字节配置回归通过。Debug构建、三模块Lint、APK签名、16KB ZIP对齐及版本检查通过；app Lint 0错误/34警告，player-mpv 0/0，video-export 0/1。新增警告为中文界面国际化与程序化View构造提示，另有TextureView位图返回值的恒真检查编译提示；并不证明真实截图内容正确。JVM不执行Android PixelCopy、Canvas或PNG编码。

## 真机验收步骤

先用普通SDR视频：原大小截图应只含视频视口；放大到2倍并拖到触球点再截图，核对可见区域一致。分别测试普通/全屏、横/竖屏及边缘位置。画三类形状与三色，撤销/清空，验证两指和越界不误画。另存PNG重新打开，核对标注位置、颜色、方向和无HUD。取消另存后继续编辑，关闭未保存编辑确认丢弃。保存选择器返回及切后台再回来，编辑应保留，退出后视频仍暂停；重新播放并验证TourBox。原视频应未修改，USB拔出仍沿用已知隔离限制。
