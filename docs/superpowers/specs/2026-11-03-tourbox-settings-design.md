# TourBox用户设置与自定义映射：简短设计

日期：2026-11-03。状态：用户已选择首版仅单次按键与旋转；设计/计划已获用户确认，Native实施及无设备检查完成，真实UI与设备验收待执行。

## 目标

将“USB诊断”入口/对话框改为“TourBox设置”，只显示连接状态、12项映射、恢复默认、保存与关闭，以及一行版本信息。移除原始日志、接口/端点/协议参数、计数、手动claim/监听、CDC请求、8字节和94字节实验按钮；后台诊断文件继续保留。不把USB私有命令暴露成可映射动作。

保留自动枚举/权限/连接及已验证初始化，系统USB权限提示仍由用户允许。连接异常仅给可操作的简短提示；USB-001的未知回收隔离不绕过，不新增自动重试或私有命令。

## 首版范围

用户确认仅单次ButtonDown与四类旋转，不做长按、双击、组合键或按键学习。ButtonUp及未知原始码不触发动作，不更改解码器或按键码表。

固定列出当前已确认的12个输入，单项下拉选动作。已有类型安全枚举可直接覆盖，固定列表不要求用户边操作控制器边选择，首版不增加学习模式。

| 输入 | 默认动作 |
|---|---|
|Knob顺时针|前进一帧|
|Knob逆时针|后退一帧|
|Scroll上滚|快进5秒|
|Scroll下滚|快退5秒|
|Knob按下|播放/暂停切换|
|Scroll按下|循环切换播放速率|
|Top按下|启用/清除AB切换|
|C1按下|记A|
|C2按下|记B|
|Short按下|不执行|
|Long/Tall按下|不执行|
|TourBox按下|不执行|

Long/Tall是实体按钮名称，不表示长按。

## 可选动作

不执行；播放/暂停切换、播放、暂停；前进/后退一帧；快进/快退5秒；速度提高一档/降低一档/循环五档，以及直接设为0.1、0.25、0.5、0.75、1倍；记A、记B、启用AB、清除AB、切换AB、回A；截图标注。

同一动作可分配给多个输入。首版不映射选文件、视频导出/另存等会启动文件选择器的操作，也不映射USB命令。截图标注使用已有受控入口，进入后暂停分发，不允许旋转事件反复弹出多个编辑器。

## 编辑、生效与保存

- 打开设置暂停视频及播放器事件分发，原始USB监听继续；关闭后恢复可控状态，保留现有不自动恢复播放的行为。若后台则沿用原USB清理与返回重连策略。
- 修改先进入草稿，点击“保存”后统一生效并保存到手机；取消/关闭不覆盖现有映射，未保存修改关闭前询问丢弃。
- “恢复默认”先重置草稿，仍需点击保存；首次安装使用上表默认映射，覆盖升级保留已保存设置。
- 使用Android已有SharedPreferences保存版本化稳定输入/动作ID，不引入新依赖；后台执行持久化，写入失败保留草稿且不报告成功，不替换当前映射。未知/损坏配置按项安全恢复默认并保留必要日志。
- 提交映射时更新绑定代次并取消旧待办，防止旧配置动作在保存后继续执行；接收时按同一份不可变配置解析。继续保留旧USB/播放器会话、前后台、过期和积压保护。
- 旋转可选择动作但不自动合并/加速；对截图、播放切换、AB切换等不适合丢弃的动作，不把它们仅因来源是旋转就当成可淘汰逐帧工作。队列满仍有明确计数/安全拒绝，不无界排队。
