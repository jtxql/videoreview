# 当前可见画面截图与标注：简短设计

日期：2026-11-02。状态：用户已确认设计和Native执行；实现及无设备验证完成，原生截图/视觉验收待真机。

## 目的与范围

用户选择保存当前可见区域：保留视频当时的1～4倍放大及拖动位置，而非完整源帧。截图只覆盖播放器视频视口，保留其中可见黑边；不包含应用按钮、HUD、进度条和系统状态栏。分辨率按该视口像素，不承诺源视频分辨率。

点击“截图标注”时暂停并冻结画面，进入静态编辑。首版提供直线、箭头、圆/椭圆，红/黄/蓝三色，撤销、清空、另存PNG、关闭；不做文字、自动识别、角度测量、自由笔、实时视频叠画或标注视频导出。工具仅在编辑时显示，不常驻主界面。

## 方案取舍

- 完整源帧截图：更适合保留完整内容，但忽略放大/拖动；本次未选择。
- 当前可见区域截图：用户已选择，适合局部动作观察；输出清晰度受屏幕视口限制。
- 已批准的实现建议：通过Android已有SurfaceView PixelCopy或TextureView位图能力读取视频渲染层，再按冻结的视口缩放/平移裁切并合成标注。避免整窗口截图混入界面，也不更换mpv或USB实现；不安装新依赖。

固定libmpvKt 0.3.0的MpvView为FrameLayout，内部按渲染选项创建SurfaceView/TextureView，现有ReviewPlayerView仅变换MpvView。实现时核对实际子View与尺寸，遇到不支持的渲染结构明确失败，不输出未经核实的替代截图。不能仅依靠普通View.draw捕获Surface视频。

## 操作与布局

- 普通界面在底部现有USB诊断同一行增加截图入口，不新增长驻控制行。
- 全屏提供一个小截图入口；编辑在当前Activity内弹出独立编辑面板，原视频保持暂停，横竖屏可用。
- 编辑面板中按下拖动产生一个形状，松手提交；撤销移除最后一个形状，清空只清除标注。用归一化图片坐标存储，避免预览留白或旋转导致落点漂移；两指及跨出图片的手势不提交错误形状。
- 另存使用系统创建文档选择器，PNG合并原截图与标注，在后台编码写文件；只有写入及关闭成功才报告保存成功。取消另存保留当前编辑，关闭有未保存修改时询问是否丢弃。
- 编辑期间暂停TourBox播放器分发及屏幕播放操作，保留原始USB监听；退出后恢复可控状态，视频保持暂停，不自动播放。若系统另存导致后台释放播放器，返回后编辑继续使用冻结图片；退出编辑时需恢复视频时也保持暂停，明确防止既有自动加载默认播放抢跑。

## 生命周期与失败

截图与导出互斥，同一时刻一个截图请求；绑定播放器会话、视口尺寸和操作代次。暂停完成后等待一次可绘制帧再读取，超时/失败不自动重试。切换视频、后台、旋转或关闭导致捕获上下文失效时丢弃迟到结果；异步复制仍使用中的Bitmap不可提前回收。

编辑及保存期间持有明确的图像所有权，取消/重复点击/迟到保存回调不重复写入或使用已释放图片。后台编码不引用Activity；失败保留当前编辑供用户手动重试，尽力清理本次创建的半成品，绝不写源视频。进程被杀后的未保存编辑恢复不在首版范围。

HDR色彩和硬件Surface捕获效果需真机检查；不把API成功返回等同于图像正确。内存不足、无有效帧、无效尺寸应提示失败，不能伪报成功。
