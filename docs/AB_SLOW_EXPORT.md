# A/B慢动作导出：首版实现

当前版本0.5.0-ab-export/code10。用户已批准[方案](AB_SLOW_EXPORT_PLAN.md)和依赖下载；先前功能已提交为`568fb89 feat: add TourBox playback controls and review gestures`。本轮导出修改留在工作区，不自动提交、安装或访问设备。

## 使用方法

1. 打开视频，使用屏幕或C1/C2标记A/B，满足0≤A<B≤视频时长；无需启用循环。
2. 调到希望导出的倍速（0.1/0.25/0.5/0.75/1），退出全屏，在可滚动控件区点击“导出A/B慢动作”。
3. 应用暂停播放并从核心读取实际速度/时长，冻结视频会话、URI及A/B；确认框列出区间、倍速和预计时长，选择保留源音频或静音。
4. 点击“开始生成”，保持应用前台，可查看进度或“取消/丢弃片段”。例如10秒区间、0.25倍速预期约40秒，0.1倍速约100秒。
5. 显示Ready/临时片段核验完成后点击“另存视频”，用系统文档选择器创建新的MP4。只有复制、刷新及输出流关闭成功才显示Saved；100%或编码回调不等于已保存。
6. 取消保存选择器仍可再次另存当前片段，也可丢弃。临时文件只保证当前Activity/进程内可重试，关闭应用或被系统杀死不保证可恢复，请及时另存。

## 工程与接口

- `:video-export`：独立Android库，不依赖USB或播放器。固定Media3 Transformer/effect/common 1.11.1，同版本传递模块；真实AAR API已核对，未升级AGP/Gradle/Kotlin/JDK或安装NDK。依赖解析25个运行时产物合计11,208,704字节（不是APK增量），固定Media3 AAR哈希见模块dependency-manifest.json。
- `PlayerController.prepareExport`：主线程接纳、后台暂停并读取核心Speed/Duration，冻结已有LoopPoints；每次读取前后核对播放器代次和连接对象。旧会话/后台回调由界面epoch拒绝，不导出后来选择的文件。
- `ClipExportRequest`：不可变源会话/URI、A/B微秒、速度和音频选项，验证有限数值与范围，派生成片预期时长。
- `ClipExportGate`：Preparing→Exporting→Ready→Saving→Saved；错误/取消是明确分支，Saving失败可回Ready重试。旧id、重复开始、取消后完成及关闭后的回调不改变新任务。
- `ClipExporter`：Transformer只在主线程访问；源检查、结果核验、复制和文件清理由一个文件工作线程串行执行。`ClipExportLease`保护进程级单任务，旧清理不能释放新任务所有权。
- `ClipStreamCopy`与`ClipSaveCommit`：精确核对复制字节数，验证flush/输入与输出close均成功；取消与保存提交原子互斥。若保存已提交，迟到取消会报告已保存，不能声称撤销了目标成片。

## 导出规则与核验

使用H.264/AAC MP4；音频与视频一起应用SpeedProvider，不要求分享方播放器再设慢放。设备媒体音量不写入成片，声音是否保留由导出对话框决定。默认音调可随速度变化，不承诺恒音调或声音效果；静音明确移除音轨，不静默将有声任务降为静音。

裁剪使用固定AAR已确认的微秒接口；setEndPositionMs字节码先将毫秒转微秒再调用setEndPositionUs，避免文档单位笔误。A/B是源时间轴，成片是一次片段而非无限循环。快剪和MP4 edit-list优化显式关闭，不输出仅用隐藏预滚数据模拟裁剪的文件；相关实验API声明仅用于关闭这些开关。

编码回退关闭；fallback回调会停止导出，不静默降分辨率。完成后另用MediaExtractor检查输出非空、视频/音轨、源与输出尺寸（允许旋转交换宽高）及大致变速时长。时长容差为250ms、两源帧经变速后的时长、预期时长1%中的较大者；源帧率未知时使用1秒容差。该检查用于排除明显未变速/截取错误，不证明逐帧或音画同步精度。

## 首版范围和已知限制

- 优先验证SDR、单视频轨；保留音频限单音轨。HDR/杜比视界、多视频轨以及有声多音轨明确拒绝；多音轨可由用户选择静音。字幕、图像叠字和插帧不在本版范围。
- 实际编解码能力依赖设备；mpv能播放不等于Media3能导出。导出时暂停mpv，但仍可能存在硬件资源竞争；不因失败盲目升级库或静默更改格式。4K/高帧率与实际输出方向需单独验收。
- 缓存启动门槛32MiB，不能保证整个导出空间足够；编码中空间耗尽会失败。成片时长随低速增大，不保证文件大小或耗时。
- 导出中临时暂停屏幕及TourBox播放器分发，清空旧待办；USB原始接收和初始化代码不改。结束后按原偏好恢复，只接收新事件。另存选择器可能触发后台并沿用原USB关闭/返回自动连接策略。
- 首版不做后台编码服务。编码/源检查/另存中进入后台会取消；Ready片段在保存选择器后台期间保留。进入后台仍按原规则释放播放器，保存后返回可能重新加载并重置播放位置/AB标点，导出片段使用冻结参数不受影响。
- 取消先停止Transformer，再由文件线程等前置IO结束后清理私有缓存；若取消抛异常，不强行删仍可能使用的文件/释放进程所有权，会报告回收未知。源提供方若阻塞IO，清理须等其返回，不从其他线程强关正在使用的对象。
- 保存失败尽力删除目标半成品，失败会提示用户检查；仅对用户另存创建的目标操作。相同URI、同authority/documentId或可识别的canonical别名拒绝覆盖源文件。
- 未另存临时片段可在当前页面丢弃；异常杀进程可能留下应用缓存，由后续缓存管理处理，不把它当已保存成片。源视频从不作为导出写入目标。
